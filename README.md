# ChemLab SafeLook 🧪🔬

> A mobile-friendly chemistry laboratory equipment lookup and safety documentation guide with high-resolution imagery, GHS hazard profiles, PPE checklists, and standardized operating procedures (SOP).

---

## ✨ Features

- **Standardized Equipment Catalog**: Lookup over 24+ essential laboratory apparatus across:
  - Precision Volumetric Glassware (Burettes, Volumetric Flasks, Erlenmeyers, Condensers, Sep Funnels)
  - Heating & Thermal Systems (Hotplate Magnetic Stirrers, Heating Mantles, Bunsen Burners)
  - Analytical Instruments (4-decimal Analytical Balances, pH Meters, UV-Vis Spectrophotometers)
  - Separation & Vacuum Apparatus (Rotary Evaporators, Büchner Funnels, Vacuum Desiccators, Centrifuges, Columns)
  - Safety Containment & Emergency Installations (Chemical Fume Hoods, Emergency Deluge Showers & Eyewashes, Chemical Spill Kits)
- **High-Resolution Photography & Resilient Schematics**: Includes authentic studio photography and custom vector blueprint schematics with zero broken-image fallbacks.
- **Globally Harmonized System (GHS) Hazard Diamonds**: Official GHS pictograms, risk profiles, and safety measures.
- **Personal Protective Equipment (PPE) Verification**: OSHA/ACS standards for eye, face, hand, body, and respiratory protection.
- **Standard Operating Procedures (SOP)**: Step-by-step pre-inspection, safe operation, decontamination, and emergency protocols.
- **Interactive Pre-Use Bench Clearance**: Interactive inspection checklist for bench verification prior to running experiments.
- **Chemical Incompatibility Warnings**: Specific chemical reagents and conditions that react adversely with equipment materials.
- **Mobile Thumb Ergonomics & Dark Mode**: One-handed bottom navigation bar, quick-access emergency SOS drawer, and system-adaptive light/dark themes.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone or download the repository:
   ```bash
   git clone <your-repo-url>
   cd chemlab-safelook
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` (or the port specified in terminal) in your browser.
